# راهنمای فارسی استفاده از Digikala Auto Uploader

این پروژه برای ساخت و ثبت خودکار محصول در پنل فروشندگان دیجی‌کالا (دسته 6946: تابلو) طراحی شده است.

## 1) پیش‌نیازها

- Node.js نسخه 14 یا بالاتر
- npm یا pnpm
- حساب فعال فروشنده دیجی‌کالا
- فایل CSV محصولات
- تصاویر محصول روی سیستم (فایل محلی)

بررسی نسخه Node:

```bash
node --version
```

## 2) نصب پروژه

در مسیر پروژه اجرا کنید:

```bash
pnpm install
```

اگر pnpm ندارید:

```bash
npm install
```

## 3) تنظیم کوکی احراز هویت

ابزار از متغیر `DIGIKALA_COOKIE` استفاده می‌کند.

روش پیشنهادی: فایل `.env` بسازید و مقدار کوکی را داخل آن قرار دهید:

```env
DIGIKALA_COOKIE="PASTE_FULL_COOKIE_HERE"
```

نکته مهم:

- کوکی/توکن زمان‌دار است؛ اگر خطای 401 گرفتید، کوکی جدید از پنل Seller بگیرید.
- کوکی را در git کامیت نکنید.

## 4) آماده‌سازی CSV

الگوی ستون‌ها را از فایل `products.csv` و توضیحات کامل را از `CSV-SPEC.md` بردارید.

حداقل نکات ضروری:

- `brand_id` معتبر باشد.
- `model` خالی نباشد.
- یکی از `division_id` یا `division_label` یا `painting_type` را بدهید.
- `general_mefa_id` یکی از `domestic` یا `imported` (یا 893/894) باشد.
- `title_fa` خالی نباشد.
- `image_paths` شامل مسیر فایل‌های واقعی باشد.

### قانون مهم تصاویر (بر اساس تست واقعی)

- حداقل 2 تصویر لازم است.
- فقط فرمت `jpg` یا `jpeg` پذیرفته می‌شود.
- مسیر هر تصویر باید روی سیستم وجود داشته باشد.
- تصاویر را با `|` جدا کنید.

نمونه:

```csv
images/tabloo_001_main.jpg|images/tabloo_001_side.jpg
```

## 5) دستورات اصلی

### فقط اعتبارسنجی CSV

```bash
node cli.js --validate products.csv
```

یا:

```bash
pnpm run validate
```

### آپلود تعاملی (پیشنهادی)

```bash
node cli.js --upload products.csv
```

یا:

```bash
pnpm run upload
```

### حالت Dry Run (بدون API واقعی)

```bash
node cli.js --dry-run products.csv
```

یا:

```bash
pnpm run dry-run
```

### اجرای مستقیم آپلودر اصلی

```bash
node digikala-uploader.js products.csv
```

یا:

```bash
pnpm run uploader
```

## 6) ترتیب واقعی مراحل API

در اجرای موفق نهایی، ترتیب زیر استفاده شده است:

1. `POST /product-creation/product/detail/validation` (ساخت draft و گرفتن `draft_product_id`)
2. `POST /product-creation/attributes` (ذخیره ویژگی‌ها و ابعاد)
3. `POST /product-creation/auto-title/save` (ذخیره عنوان)
4. `POST /product-creation/images/upload` (آپلود تک‌تک تصاویر)
5. `POST /product-creation/save` (نهایی‌سازی با `photos_detail`)

## 7) خطاهای رایج و راه‌حل سریع

### خطای 401 Unauthorized

علت: کوکی یا توکن منقضی/نامعتبر است.

راه‌حل:

- کوکی جدید از seller.digikala.com بردارید.
- مقدار `DIGIKALA_COOKIE` را آپدیت کنید.

### خطای تصویر (Image not found)

علت: مسیر اشتباه یا فایل وجود ندارد.

راه‌حل:

- مسیرها را نسبت به مسیر اجرای پروژه چک کنید.
- از مسیرهای واقعی و قابل دسترس استفاده کنید.

### خطای فرمت تصویر

علت: PNG یا فرمت غیر JPEG.

راه‌حل:

- تصاویر را به JPG/JPEG تبدیل کنید.

### خطای نهایی‌سازی محصول

علت رایج: تعداد تصویر کمتر از 2.

راه‌حل:

- حداقل دو تصویر JPG/JPEG معتبر ارسال کنید.

## 8) روند پیشنهادی عملیاتی

1. اول با `--validate` فایل CSV را چک کنید.
2. سپس با یک ردیف تستی آپلود واقعی بزنید.
3. بعد از موفقیت، فایل کامل را آپلود کنید.
4. در صورت خطا، CSV یا کوکی را اصلاح و دوباره اجرا کنید.

## 9) نکات مهم برای پایداری

- قبل از هر اجرای واقعی، اعتبار کوکی را بررسی کنید.
- نام‌گذاری تصاویر را یکدست نگه دارید.
- از جداکننده `|` بدون فاصله اضافی استفاده کنید.
- تغییرات ساختار API را در `API-SPEC.md` و `CSV-SPEC.md` همزمان به‌روز کنید.
